# 網站字型

`BreezeNotesHand.woff2` 來自 LXGW WenKai TC Regular，使用 fontTools 4.67.0 / brotli 1.2.0 將目前網站介面、英文原文和全部 1,000 筆繁中描述所需的字形子集化；依 OFL 保留原授權並將衍生字型名稱改為 Breeze Notes Hand。Kalam Bold 維持原檔。

此檔已提交，不需要在 GitHub Actions 或訪客端執行字型工具。未包含的字元使用系統楷體／serif 後備字型，不會讓頁面或搜尋失效。未來大量更換內容時可從 Google Fonts 官方來源取得新版 LXGW WenKai TC，重新製作子集並保留 OFL，或改用完整原字型。
